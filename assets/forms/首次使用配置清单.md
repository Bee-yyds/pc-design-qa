# 首次使用配置清单

本文件供代理核对字段，实际对话按[首次引导](../../references/onboarding.md)逐步进行。每轮只问1–3个相关缺项，用户在 Codex 对话中填写，配置文件由代理维护。

| 准备事项 | 用户提供的缺项 | 代理读取或验证 |
| --- | --- | --- |
| 项目与保存位置 | 项目名、版本、需求、希望保存的目录 | 当前目录、已有配置、同需求报告和索引 |
| 本轮范围 | 模块名、Figma 区域链接、开发地址、排除内容 | 文件与节点标识、相关画面和绿色研发说明 |
| 设计稿访问 | 自行连接账号并打开文件 | 节点参数、截图和绿色研发说明可读 |
| 开发页面 | 指定窗口、自行登录、需要保留的内容 | 目标元素实际样式、原始截图和控制连接 |
| 显示与样本 | 特殊显示要求、已有状态的进入方式 | 视口、缩放、像素比例、字体与可取得的状态 |
| 操作限制 | 本次交互范围、付费授权和累计上限 | 默认视觉、默认生成预算零，已有授权记录 |
| 在线交付 | 特殊可见范围，协作人员可后补 | Sites、共享存储和表格能力，既有发布身份 |

## 记录与复用

保存非敏感项目资料、各项准备状态、实际验证结果、受阻原因和下一步。不要保存密码、Cookie或令牌。技术上可读取的信息由代理获取。

首次报告仅所有者可访问，默认受邀者可以编辑描述、处理备注、研发修复和设计确认两个状态。已有报告沿用原访问设置。

缺少某项能力时，仅暂停依赖它的步骤。字体发现实际问题后再处理。用户确认连接恢复后，按完整 SOP 的有限重试规则验证。

新需求和续验复用已有配置，只补变化。原生提问功能不可用时使用对话内编号问题。
