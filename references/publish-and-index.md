# 在线交付与索引

## 新需求

读取当前Sites技能，用其官方starter准备空源码目录。不要复制旧项目.git、hosting identity、凭证、.env、数据库或截图。准备真实report.json后：

node <本技能>/scripts/apply-template.mjs --target <新Sites源码目录> --report <report.json>

该脚本遇已有data/report.json拒绝覆盖；应用业务overlay，保留官方运行/认证实现，声明D1 DB。复制真实证据到public，运行报告校验。安装、构建、D1预览/迁移、发布遵循当前Sites技能。

模板已含动态批次、全红标记、问题tab、排序、协作/冲突/历史、原图放大、精确Figma链接和MCP提示词。交付研发使用在线HTML，不提供本地HTML下载或导出功能，不自动生成或更新本地只读快照；已有历史文件保留。追加时更新原report.json，保留ID及数据库。无差异不建空卡；覆盖清单、进度和pending原因只作内部记录，每轮按SOP仅汇报用户本次明确指定范围，不渲染为在线页模块。

## 发布

新报告私有。发布后将Site ID、源码、在线地址保存项目配置并回填report.onlineUrl，交付在线链接。按明确人员授权邀请，保持既有受众；平台不支持时说明限制。

测试使用隔离数据。真实跨账号验证需要两个可用账号；只有本地模拟不能称跨账号已通过。顶部四项按整份文档统计，切换批次和排序保持一致；验证跨批次标记、独立状态、取消勾选和刷新同步。不要使用真实问题改变状态来做测试。

发布后检查两个交付边界：顶部没有本地HTML下载入口或相关下载说明，底部没有覆盖、待验或待确认说明模块及空容器。内部记录仍完整保留本轮任务与历史未完成任务。最终对话仅汇报本轮明确指定范围的结果、问题数、在线地址及未完成原因，不默认展开历史清单；只有用户明确要求续验相应历史项目或查看总览时才纳入。“本轮未完成项：无”仅适用于本轮范围。

## Excel索引

依Spreadsheets技能维护根目录设计验收文档索引.xlsx，三列：版本号、需求名、HTML 验收文档地址。版本＋需求为键，已有更新、新键追加，不记批次。

脚本：node <本技能>/scripts/update-index.mjs --file <xlsx> --version <版本> --requirement <需求> --url <URL> --runtime-modules <官方node_modules> --soffice <重算器>

使用Artifact Tool建表/导入，保留记录与筛选。HYPERLINK缓存若不支持则要求可用重算器，不把错误覆盖正式文件。按Spreadsheets技能在制表前执行操作标记；运行环境动态发现。结构非三列或键重复先报告冲突，不重建覆盖。检查保存的原生筛选和链接，再确认线上访问。

## 安装分享

安装方式和可复制的对话请求见 [README](../README.md)。由当前 Codex 安装工具发现适用的技能目录，保留自动发现。首次调用按[对话引导](onboarding.md)逐步准备，使用接收者自己的账号、文件权限、发布身份和项目目录。

开源目录包含完整技能、空白模板、校验脚本、使用说明和 GPL-3.0-only 许可证。发布前核对相对引用和隐私信息，排除真实项目配置、人员、Site ID、凭证、运行数据库、依赖缓存和验收截图。通用模板复用当前 Sites 官方基础项目，第三方依赖遵循各自许可证。

日常维护遵循 Skill 入口的分发约定。本地开源目录在用户明确要求整理发布版时同步，GitHub 发布或分享 ZIP 按当次授权执行。
