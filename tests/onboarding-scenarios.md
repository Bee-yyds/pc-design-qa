# 首次引导场景

在独立临时目录准备以下模拟信息，按入口与首次引导演练。使用 `.invalid` 或 `.test` 测试地址，权限和工具结果由场景明确给定。记录结果时注明模拟条件。

| 场景 | 给定信息 | 应观察到的行为 |
| --- | --- | --- |
| 首次使用 | 用户只说“第一次使用，没有代码基础” | 首轮最多3个相关问题，先问项目和保存位置，后续再收集链接；解释下一步动作 |
| 已知信息复用 | 已提供版本、需求、模块、两个链接和目录，尚未说明排除项 | 只补排除内容及实际缺项，从链接读取技术标识 |
| 缺少设计稿工具 | 链接已给，当前客户端未连接 Figma | 解释连接用于读取尺寸和颜色，引导实际可用的安装连接入口，保存等待条件 |
| 文件权限失败 | Figma 已连接，但指定文件读取被拒绝 | 引导用户用同一账号打开文件或申请访问，记录该文件受阻，保留已知配置 |
| 开发页截图失败 | 目标元素可读，截图失败；诊断一次和重试一次仍失败 | 保留受阻，记录失败环节和下一步，继续独立工作；恢复后只做一次读取与截图检查 |
| 中断恢复 | 项目、设计稿已准备，开发页等待登录 | 复用稳定字段，核验设计稿连接，接着准备原开发页，避免重问整套信息 |
| 老用户的新需求 | 已有配置和报告A，本次明确给出需求B和链接 | 复用窗口限制和工具配置，为B独立保存报告映射，保留A的记录 |
| 缺少在线报告工具 | 设计稿与开发页均可读取，Sites 当前不可用 | 说明在线交付所缺的工具，继续验收并保存证据，将发布列为未完成 |
| 多个状态缺少样本 | 同一模块要求默认、空态和生成中，只有默认态 | 默认态照常验收，集中询问缺少样本的进入条件，保存各状态进度 |
| 已连接答复 | 用户选择“已连接”，但最小检查再次失败 | 根据实际失败结果继续标记受阻，给出具体影响与恢复条件 |
| 原生问答不可用 | 当前环境没有原生提问工具 | 在对话中给1–3个编号问题，保留自由回复，收到答案后推进 |

## 表达检查

每个场景核对用户能否回答以下问题。

1. 现在需要我提供什么或做什么？
2. 应该在哪个页面或窗口操作？
3. 做完后怎样告诉 Codex，接下来会检查什么？

技术名出现时带用途说明，能自动读取的信息由代理获得。准备进度与验收结果分别记录。
